# Protótipo Arca de Noé

Protótipo técnico de mundo e fauna com animação procedural, criado do zero para este repositório.

## Escopo inicial

- mundo 3D procedural;
- animais quadrúpedes paramétricos;
- locomoção baseada em distância;
- ciclo de apoio e balanço das patas;
- IK de duas articulações;
- ajuste de passada, cadência e velocidade;
- laboratório de desenvolvimento para inspeção de gait e rig;
- documentação do pipeline;
- testes e CI.

> Este projeto não contém código ou assets copiados de Pilgrimage. A arquitetura foi implementada de forma independente a partir de conceitos gerais de animação procedural, IK e geração de mundo.

O restante da documentação fica em `docs/`.
