# Contribuição

Este repositório prioriza código pequeno, verificável e removível.

Toda mudança estrutural deve:

- manter `npm run typecheck`, `npm test` e `npm run build` verdes;
- adicionar teste para matemática de animação ou geração quando aplicável;
- evitar copiar código ou assets de terceiros sem licença compatível;
- documentar novos contratos;
- manter o laboratório de desenvolvimento funcional.

Commits devem descrever a mudança real. Evite commits de limpeza misturados com alterações de comportamento quando puderem ser separados.
