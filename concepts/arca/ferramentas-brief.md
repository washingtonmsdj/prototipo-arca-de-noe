# Ferramentas — referência de concept

Imagem: `ferramentas-concept-v1.png`. Ferramenta de geração integrada image_gen; versão do modelo não exposta. Prompt completo em `ferramentas-prompt.txt`.

Gênesis 6:14–22 especifica construção, compartimentos e revestimento de betume, mas não enumera ferramentas. Esta prancha usa analogias de carpintaria antiga; não identifica ferramentas comprovadamente usadas por Noé nem fixa uma data para a narrativa.

Kit proposto: machado para derrubar/desgalhar; enxó para desbastar; serra manual para serrar madeira; malho e cunhas para divisão longitudinal; formões para encaixes; furadeira de arco para furos; esquadro, vara, corda e prumo para marcação; cavilhas para união e espátula para aplicar betume. Cobre/ligas e formas são escolhas visuais, não materiais confirmados do equipamento de Noé. As cotas são referências de modelagem.

Correções para modelagem a partir da imagem: não copiar a ponta helicoidal da furadeira, que lembra uma broca moderna; usar ponta simples. Confirmar a lâmina transversal da enxó por vistas ortográficas. Betume não é sinônimo de resina: tratar o recipiente como betume, sem presumir composição. O encaixe ilustrado é esquemático; ajustar furo e cavilha para atravessar efetivamente a união. O processo admite divisão por cunhas e desbaste antes da serração; as vinhetas não são instruções operacionais completas.
